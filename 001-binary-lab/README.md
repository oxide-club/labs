# Laboratório de Representação Binária

Investigue valor numérico, bytes do host e layout. O instrumento está completo:
não é necessário implementar o encoder histórico.

Leia o [enunciado](index.md), registre suas hipóteses e siga o
[guia de execução](materials/README.md). Entregue logs, alterações instrumentais,
contraexemplos e explicações usando o [modelo de relato](report-template.md).

Os materiais em `starter/packet.c` e seus checks continuam disponíveis como
[extensão opcional](materials/legacy.md), com o contrato anterior preservado.
